# Working with Passport Auth with JWT

This project is an authentication project using Access Token and Refresh Token which follows the best practices at the moment. It create refresh Token on the database and send it as cookies and serves access token to authorization header.

The frontend is hosted on Vercel [here](https://auth-passport-with-jwt.vercel.app/). 

The backend is hosted on Render [here](https://passport-authentication-with-json-web.onrender.com)


## The Technologies Used
- Database: Mongdb
- ORM: Moongose
- Authentication: Passoport Local with JWT
- Frontend: Nextjs
- Backend: ExpressJs
- Component: Shadcn
- CSS: Tailwind
